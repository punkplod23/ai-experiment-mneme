## LLM Output below
Mneme is an experimental text generation and semantic search engine built in Rust. 

The project explores alternative cognitive architectures where concepts are represented as high-dimensional bit vectors, and reasoning is performed via algebraic operations (XOR, bundling, permutation) rather than floating-point matrix multiplication.
